# Walkthrough

Este é um Walkthrough para saber o que fazer no repositório [horta-demo-vuln](https://github.com/Gustavo-Vieira-Unasp/horta-demo-vuln), tentando corrigir as vulnerabilidades e claro, explicando os passos tomados.

## Análise

Você vai chegar no clone do repositório e vai encontrar arquivos estruturados como:

* [main.py](./walkthrough/old_files/main.py.md)
* [Dockerfile](./walkthrough/old_files/_Dockerfile.md)
* [config.py](./walkthrough/old_files/config.py.md)
* [requirements.txt](./walkthrough/old_files/requirements.txt.md)

Estes arquivos são os principais causadores de problemas, e devem ser corrigidos. Verifique [analysis.md](./walkthrough/analysis.md) para saber o que fazer.

## Consertando Vulnerabilidades

Depois de fazer a análise de erros, vamos reparar as vulnerabilidades do repositório. Confira [vulnerability_fixing.md](./walkthrough/vulnerability_fixing.md)
